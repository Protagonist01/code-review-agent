# Security

This project is experimental, with no supported production release or promised response time.

Do not report credentials, private source code, or exploitable vulnerability details in public issues. Use the repository Security tab's private vulnerability reporting option if enabled. If unavailable, ask the maintainer to enable private reporting without including vulnerability details.

Privately provide the affected revision, impact, and minimal reproduction. Test only services you control.

Keep credentials outside version control. Limit the GitHub App to required repositories. Hosted providers receive diff and context text; review their data handling before connecting private repositories. Treat model output as untrusted advice.
